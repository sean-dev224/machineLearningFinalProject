To run this project:
1. Pull this repository: '''git clone https://github.com/sean-dev224/machineLearningFinalProject.git'''
2. In the project directory, create a python virtual environment: '''python3 -m venv venv'''
3. Source the environment: '''source venv/bin/activate'''
4. Install required packages: '''pip install -r requirements.txt'''
5. Run the code in the notebooks to view project visualizations and results
